# Kamaliev/tap

Homebrew tap for [Kamaliev](https://github.com/Kamaliev) projects.

```sh
brew install --cask Kamaliev/tap/clipvault
```

| Cask | Description |
|---|---|
| [clipvault](https://github.com/Kamaliev/clipvault) | Encrypted 24-hour clipboard history for macOS |

Casks are updated automatically by the release workflow of each project.
